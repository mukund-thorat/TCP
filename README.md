# 🔌TCP (Layer 4)  
  
## 👀 Overview  
This project demonstrates how TCP (the OSI model's 4th layer) works in action.  
It focuses on core transport-layer concepts like connection setup, reliable  
delivery, and basic client/server communication patterns.  
  
## ⚡ Quick Start  
1) Install uv (if you do not have it already):  
  
    ```bash
    pip install uv
    ```
  
2) Install dependencies (if a `pyproject.toml` is present):  
  
    ```
    cd src
    uv sync
    ```
